Переделка экрана "Заявки" — итерация 4 (финальная)

ЗАДАЧА: Превратить экран в master-detail layout с левой колонкой списка 
и правой панелью деталей. Добавить расширенную систему фильтров. 
Использовать табличный (тонкий) формат карточек.

================================================================
ЧАСТЬ 1. ОБЩАЯ СТРУКТУРА ЭКРАНА
================================================================

Экран "Заявки" разделён на две колонки:
- ЛЕВАЯ КОЛОНКА (~60% ширины) — список заявок с фильтрами
- ПРАВАЯ ПАНЕЛЬ (~40% ширины) — детали или сводка дня

Между колонками — тонкий вертикальный разделитель #E2E8F0.

В правом верхнем углу правой панели — кнопка "свернуть панель" 
(иконка ChevronRight из lucide-react). При сворачивании список 
занимает всю ширину экрана.

================================================================
ЧАСТЬ 2. ЛЕВАЯ КОЛОНКА — СПИСОК ЗАЯВОК
================================================================

2.1 ТАБЫ ПО СТАТУСАМ (верхний уровень фильтрации):

[Все 45] [Новые 5] [Планирование 12] [Выход 8] [Закрытие смен 3] 
[Согласование смен 4] [Выплата 2] [Завершено]

По умолчанию активен "Все". Активный таб — синий текст #4877A5 
с подчёркиванием 2px.

2.2 СТРОКА С ФИЛЬТРАМИ-ЧИПАМИ И ПОИСКОМ (под табами):

Слева — кнопка [+ Фильтр] (открывает dropdown с выбором измерения 
фильтрации: Клиент / Объект / Зона / Дата / Координатор / Проблемы).

После клика на "+ Фильтр" и выбора значения — появляется чип типа:
[Клиент: Лента ✕]  [Зона: Красная ✕]  [Дата: Сегодня ✕]

Чипы — скруглённые (20px), лёгкий серый фон #F1F5F9, с иконкой 
X (lucide) для удаления.

Справа в этой же строке — поисковая строка:
[🔍 Поиск по клиенту, объекту, номеру...]
Поиск занимает ~30% ширины строки, справа от чипов.

2.3 ТАБЫ ПО ДАТАМ (под строкой фильтров):

[Сегодня 12] [Завтра 23] [Далее 45]

2.4 ТАБЛИЧНЫЙ ФОРМАТ КАРТОЧКИ ЗАЯВКИ (ключевое изменение):

Карточки теперь ТОНКИЕ, одна строка высотой ~56-64px.
Структура каждой строки:

┌──┬─────────────────────┬──────────────┬──────────────┬─────────────┐
│  │ КЛИЕНТ · ОБЪЕКТ     │ ДАТА/ВРЕМЯ   │ 15 / 12 / −3 │ ⚠ проблемы  │
└──┴─────────────────────┴──────────────┴──────────────┴─────────────┘

Компоненты строки (слева направо):

а) Цветная полоска слева 4px высотой всей карточки:
   - Зелёная #22C55E
   - Оранжевая #EAB308
   - Красная #EF4444

б) Фон всей карточки — ОЧЕНЬ СЛАБАЯ подсветка в цвет зоны:
   - Зелёная: #F0FDF4
   - Оранжевая: #FEFCE8
   - Красная: #FEF2F2

в) Колонка "Клиент · Объект" (~40% строки):
   Текст "Лента · БЦ Столица"
   Montserrat, 14px, weight 600, цвет #0F172A

г) Колонка "Дата/Время" (~20%):
   "15.05 09:00"
   Nunito Sans, 13px, цвет #475569
   Без иконки календаря (чтобы не было визуального шума).

д) Колонка "Цифры" (~20%) — КРИТИЧНО ВАЖНАЯ ЧАСТЬ:
   
   Три числа через слеш с цветовой индикацией:
   
   "15 / 12 / −3"
   
   - Первое число (заявка/нужно) — обычный цвет #0F172A
   - Второе число (запланировано) — обычный цвет #0F172A
   - Третье число (резерв) с цветом:
     * ОТРИЦАТЕЛЬНОЕ (−3, −11) — красным #EF4444, bold
     * ПОЛОЖИТЕЛЬНОЕ (+2, +5) — зелёным #22C55E, bold  
     * НОЛЬ (0) — серым #64748B
   
   Все три числа — одинаковый размер шрифта ~14px, моноширинный 
   шрифт для цифр (font-family: 'SF Mono', Monaco, monospace), 
   чтобы визуально выравнивалось.
   
   Подсказка при наведении на блок с цифрами (tooltip):
   "Нужно по заявке: 15
    Запланировано: 12
    Резерв: −3 (недобор)"

е) Колонка "Проблемы" (~20%):
   
   Только если есть проблемы — показываем бейджи в компактном виде:
   
   ⚠ координатор  — если не назначен
   ⚠ срочная      — если до начала < 4ч
   ⚠ НПД          — если процент ниже порога
   
   Иконка AlertTriangle (lucide), 14px, цвет соответствует 
   цвету зоны (красный для красных заявок, оранжевый для жёлтых).
   
   Текст бейджа мелкий, 12px, цвет #475569.
   
   Если проблем НЕТ — эта колонка пустая (не показываем 
   никаких "ок" или зелёных галочек — используем "show only 
   abnormalities" принцип).

ж) Стрелка → в самом конце строки:
   Иконка ChevronRight (lucide), 16px, цвет #94A3B8.
   Появляется при наведении на строку.

2.5 СОСТОЯНИЕ ВЫБРАННОЙ КАРТОЧКИ:

Когда пользователь кликает на заявку — она выделяется:
- Чуть более тёмный фон (например, зелёная карточка становится #DCFCE7)
- Тонкая рамка 1px #4877A5
- В правой панели появляются детали именно этой заявки

2.6 ПРИМЕРЫ КАРТОЧЕК (ВСЕГО 7-8 ШТУК РАЗНЫХ):

Зелёная, всё хорошо:
█ Лента · БЦ Столица        15.05 09:00    15 / 15 / 0       (пусто)        →

Зелёная с резервом:
█ БизнесПарк · БЦ Кристалл  16.05 09:00    6 / 8 / +2        (пусто)        →

Оранжевая, нет координатора:
█ Метро · ЖК Северный       15.05 08:00    20 / 18 / −2      ⚠ координатор  →

Красная, срочная, недобор:
█ Стройгарант · ЖК Восток   15.05 08:00    15 / 4 / −11      ⚠ срочная ⚠ НПД →

Красная, большой недобор:
█ Логистик+ · Склад         16.05 07:00    25 / 10 / −15     ⚠ НПД          →

================================================================
ЧАСТЬ 4. ОБЩИЕ ТРЕБОВАНИЯ К ВИЗУАЛУ
================================================================

- ЗАПРЕЩЕНО использовать эмодзи. Все иконки — только SVG из 
  библиотеки lucide-react.

- Иконки lucide-react по контекстам:
  • Поиск → Search
  • Фильтр → Filter или SlidersHorizontal
  • Удалить чип → X
  • Свернуть панель → ChevronRight
  • Назад → ChevronLeft
  • Открыть заявку → ChevronRight
  • Предупреждение → AlertTriangle
  • Звезда рейтинга → Star
  • Координатор (badge в карточке исполнителя) → Shield или UserCheck

- Цвета:
  • Primary orange: #FF9900
  • Primary blue: #4877A5
  • Green: #22C55E, светло: #F0FDF4
  • Yellow: #EAB308, светло: #FEFCE8
  • Red: #EF4444, светло: #FEF2F2
  • Text primary: #0F172A
  • Text secondary: #475569
  • Text muted: #64748B
  • Border: #E2E8F0
  • Background secondary: #F8FAFC

- Шрифты:
  • Заголовки: Montserrat (500/600)
  • Текст: Nunito Sans
  • Цифры (для моноширинного выравнивания): 'SF Mono', 'Monaco', monospace

- Скругления: 8px карточки, 6px кнопки, 20px chips

- Плотность: Карточки тонкие (56-64px), отступ между карточками 
  6-8px (плотный список).

- При наведении на карточку — лёгкий hover-эффект:
  • Курсор pointer
  • Стрелка → становится ярче

================================================================
ЧАСТЬ 5. ЧЕГО НЕЛЬЗЯ ДЕЛАТЬ
================================================================

- НЕ показывать "Health score" как число или бейдж. Про рейтинг 
  заявки мы забыли — остались только цифры заявка/запл./резерв.
- НЕ показывать зелёные галочки "Координатор назначен" в карточках. 
  По умолчанию он всегда назначен — показываем только аномалии.
- НЕ использовать эмодзи (🟢🟡🔴📅👥📊🎯⚠️✅).
- НЕ создавать толстых карточек на 3 строки — только тонкий 
  табличный формат.
- НЕ добавлять виджеты "Баланс спроса" и "SLA 17:00" в левую часть.
