Переделка экрана "Заявки" — итерация 5 (финальная)

ЗАДАЧА: Master-detail layout с ультра-плотным табличным списком 
заявок слева и информативной панелью справа. Современная визуальная 
иерархия по принципу Linear / Notion / Stripe (минимум шума, 
максимум сигнала).

================================================================
ЧАСТЬ 1. ОБЩАЯ СТРУКТУРА
================================================================

Двухколоночный layout без промежуточных виджетов:

- Левая часть ~60% — список заявок
- Правая панель ~40% — сводка дня ИЛИ детали выбранной заявки
- Разделитель 1px #E2E8F0 между колонками

Кнопка "свернуть панель" (иконка PanelRightClose из lucide-react) 
в правом верхнем углу правой панели. Свёрнутая панель — 
список растягивается на всю ширину.

================================================================
ЧАСТЬ 2. ЛЕВАЯ КОЛОНКА — ЗАГОЛОВОК И ФИЛЬТРЫ
================================================================

2.1 ТАБЫ ПО ЭТАПАМ ПАЙПЛАЙНА (верхняя полоса):

Одна горизонтальная строка, названия этапов на русском с счётчиком:

[Все 45] [Новые 5] [Планирование 12] [Выход 8] [Закрытие смен 3] 
[Согласование смен 4] [Выплата 2] [Завершено]

Активный таб: синий текст #4877A5, подчёркивание 2px снизу.
Неактивные: серый #64748B, без подчёркивания.
Шрифт: Nunito Sans 14px.

По умолчанию активен "Все".

2.2 СТРОКА ФИЛЬТРОВ (под табами):

Слева — кнопка [Фильтр] с иконкой Filter (lucide) слева от текста.
При клике — открывается dropdown со следующими полями:

┌─────────────────────────────┐
│ ФИЛЬТРЫ                      │
│                              │
│ Период         [Сегодня ▼]   │
│ Клиент         [Все ▼]       │
│ Объект         [Все ▼]       │
│ Статус         [Все ▼]       │
│ Координатор    [Все ▼]       │
│ С проблемами   [Все ▼]       │
│                              │
│ ───────────                  │
│ СОРТИРОВКА                   │
│ [Дата создания ▼]            │
│ ○ По возрастанию             │
│ ● По убыванию                │
│                              │
│ [Сбросить]  [Применить]      │
└─────────────────────────────┘

По умолчанию фильтр установлен: Период=Сегодня, Сортировка=Дата 
создания (убывание). Все остальные фильтры = "Все".

После применения фильтров — появляются чипы выбранных значений 
справа от кнопки "Фильтр" (если они отличаются от дефолта):

[Фильтр]  [Период: Сегодня ✕]  [Зона: Красная ✕]

Чипы удаляются кликом на X.

Справа в той же строке — поиск:
[иконка Search] Поиск по клиенту, объекту, номеру...

Поле поиска занимает ~30% ширины строки фильтров, расположено 
справа.

УБРАТЬ ПОЛНОСТЬЮ табы дат "Сегодня / Завтра / Далее" — 
период теперь только через фильтр.

ЧАСТЬ 3. ЛЕВАЯ КОЛОНКА — СПИСОК ЗАЯВОК
================================================================

3.1 ФОРМАТ СТРОКИ ЗАЯВКИ:

Высота строки: 36px (очень плотная table row).
Между строками: без отступа, только 1px разделитель #F1F5F9.

Структура строки слева направо:

┌─┬──────┬─────────────────────────────┬───┬─────────────────────┬──────────────┬──┐
│█│ 15.05│ Лента · БЦ Столица          │⚠ │ [Планир. завершено] │ 15 / 12 / −3 │ →│
└─┴──────┴─────────────────────────────┴───┴─────────────────────┴──────────────┴──┘

Колонки:

(a) ЦВЕТНАЯ ПОЛОСА СЛЕВА (4px):
   - Красная #EF4444 — если есть проблема на текущем этапе
   - Отсутствует (0px) — если всё в порядке

(b) ДАТА (~60px):
   Формат "15.05" (только день.месяц, без года, без времени).
   Шрифт: Nunito Sans 13px, цвет #475569.
   Tooltip при наведении: полная дата и время "15.05.2026 09:00".

(c) КЛИЕНТ · ОБЪЕКТ (flex 1, растягивается):
   Текст "Лента · БЦ Столица".
   Шрифт: Nunito Sans 14px, weight 500, цвет #0F172A.

(d) ИНДИКАТОР ПРОБЛЕМЫ (~32px):
   - Если есть проблема на этапе: иконка AlertTriangle (lucide), 
     14px, цвет #EF4444.
   - Если проблем нет: пусто (не показываем галочку или OK).
   - Tooltip при наведении на иконку: перечисление проблем 
     текстом.

(e) СТАТУС-БЕЙДЖ (~180px):
   Pill-бейдж со скруглением 12px, padding 4px/10px, шрифт 
   12px/weight 500, моноширинный не нужен.
   
   Цветовая палитра по статусам (фон / текст):
   - Создана                #F1F5F9 / #475569
   - Передана в работу      #F5F3FF / #6D28D9
   - Планирование завершено #DBEAFE / #1E40AF
   - Выход отслежен         #CFFAFE / #0E7490
   - Смены закрыты          #FEF9C3 / #854D0E
   - Смены согласованы      #DCFCE7 / #166534
   - Выплаты произведены    #D1FAE5 / #065F46
   - Завершена              #F1F5F9 / #475569

(f) АДАПТИВНЫЕ ЦИФРЫ (~120px):
   Формат зависит от текущего этапа заявки.
   Шрифт: 'SF Mono', Monaco, monospace 13px, цвет #0F172A.
   
   По этапам:
   - Создана                  → "15"              (только нужно)
   - Передана в работу        → "15 / 12"         (нужно / запл.)
   - Планирование завершено   → "15 / 12 / −3"    (нужно / запл. / резерв)
   - Выход отслежен           → "12 / 11"         (запл. / вышло)
   - Смены закрыты            → "96ч / 100ч"      (закрыто / всего)
   - Смены согласованы        → "100ч / 96ч"      (заказчик / факт)
   - Выплаты произведены      → "11 / 12"         (выплачено / всего)
   - Завершена                → пусто или "—"
   
   В резерве (−3, +2) ЦВЕТ:
   - Отрицательное: #EF4444, weight 600
   - Положительное: #22C55E, weight 600
   - Ноль: #64748B
   
   Tooltip при наведении на блок цифр: 
   "Нужно: 15 | Запланировано: 12 | Резерв: −3"

(g) СТРЕЛКА (~24px):
   Иконка ChevronRight (lucide), 14px, цвет #CBD5E1.
   Появляется ярче (цвет #64748B) при наведении на строку.

3.2 СОСТОЯНИЯ СТРОКИ:

- Normal: белый фон, или #FEF2F2 если проблема на этапе
- Hover: фон #F8FAFC, курсор pointer, стрелка ярче

================================================================
ЧАСТЬ 7. СТРОГО НЕЛЬЗЯ
================================================================

- Эмодзи в интерфейсе — только SVG lucide-react
- Health score как число или бейдж (этой концепции больше нет)
- Жирные цветные кричащие бейджи с высокой насыщенностью
- Толстые карточки на 2+ строки (только 36px одна строка)
- Виджеты "Баланс спроса" / "SLA 17:00" на этом экране
- Табы дат "Сегодня / Завтра / Далее" (период — только в фильтре)
- Дублирование информации (например, цвет + число + текст одного 
  и того же статуса одновременно)

КЛЮЧЕВАЯ ИДЕЯ: 
Профессиональный SaaS-интерфейс в стиле Linear/Notion/Stripe. 
Плотная табличная информация, минимум визуального шума, 
сигналы проблем только где они реально есть. 
Цвета — pastel, приглушённые. Моноширинные цифры для выравнивания. 
Статусы различимы через цвет бейджей, но без "кричащих" оттенков.
