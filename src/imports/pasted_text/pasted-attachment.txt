Две правки в модуле "Заявки":
1. Унификация кнопки сворачивания/разворачивания правой панели
2. Добавление вида "Сетка" в дополнение к "Списку"

================================================================
ЧАСТЬ 1. КНОПКА СВОРАЧИВАНИЯ/РАЗВОРАЧИВАНИЯ ПАНЕЛИ
================================================================

ПРОБЛЕМА: Сейчас кнопки сворачивания и разворачивания правой панели 
находятся в разных местах:
- Когда панель развёрнута — кнопка находится внутри правой панели
- Когда панель свёрнута — кнопка находится в другом месте на краю экрана
Это создаёт ощущение, что кнопки "разные", хотя должна быть одна.

РЕШЕНИЕ: Кнопка должна быть в одной и той же координате независимо 
от состояния панели. Меняется только иконка.

Координата кнопки: на стыке между левой колонкой и правой панелью, 
на вертикальной линии разделителя. Кнопка "сидит" на этой линии.

Размер кнопки: круглая или квадратная 28×28px, фон #FFFFFF, 
обводка 1px #E2E8F0, тень shadow-sm. Центрирована вертикально 
относительно высоты основной области экрана.

Состояния:

ПАНЕЛЬ РАЗВЁРНУТА:
- Кнопка на разделителе между колонками
- Иконка: PanelRightClose (lucide), 16px, цвет #64748B
- Tooltip при наведении: "Свернуть панель"
- При клике: правая панель сворачивается, левая колонка 
  растягивается на всё пространство

ПАНЕЛЬ СВЁРНУТА:
- Кнопка в той же координате (на правом краю основной области)
- Иконка: PanelRightOpen (lucide), 16px, цвет #64748B
- Tooltip: "Развернуть панель"
- При клике: правая панель появляется снова, занимает 50% ширины

Анимация: переход 200ms ease.

================================================================
ЧАСТЬ 2. ПЕРЕКЛЮЧАТЕЛЬ ВИДОВ "СПИСОК / СЕТКА"
================================================================

В модуле "Заявки" сверху над списком заявок добавить переключатель 
видов. По умолчанию активен "Список" (текущий вид master-detail).

Размещение переключателя: в строке вверху слева, перед кнопкой 
"Фильтр":

[ Список ●  ]  [ Сетка  ]   [Фильтр]  [чипы...]   [Поиск...]

Стиль переключателя:
- Группа из двух кнопок, объединённых рамкой
- Активная кнопка: фон #EFF6FF, текст #4877A5 weight 600, 
  иконка слева
- Неактивная: фон #FFFFFF, текст #64748B
- Padding 6px 12px каждая
- Между кнопками тонкий разделитель 1px #E2E8F0
- Скругление 6px у группы

Иконки:
- "Список" — List (lucide) 14px
- "Сетка" — LayoutGrid (lucide) 14px

При переключении на "Сетка" — список заявок и правая панель деталей 
скрываются. Вместо них во всю ширину экрана появляется сетка 
планирования.

При переключении обратно на "Список" — возвращается текущий вид.

================================================================
ЧАСТЬ 3. ВИД "СЕТКА" — СТРУКТУРА
================================================================

3.1 ВЕРХНЯЯ ПАНЕЛЬ УПРАВЛЕНИЯ:

В строке над таблицей:

Слева:
- Переключатель периода [Сегодня + 7 дней ▼]
  Варианты dropdown:
    • Сегодня + 7 дней (по умолчанию)
    • Сегодня + 14 дней
    • Этот месяц
    • Произвольный период (открывает date-range picker)
- Кнопка [< Назад] [Сегодня] [Вперёд >] для перелистывания периода

Справа:
- Кнопка [Свернуть всё] / [Развернуть всё] — управление 
  свёрнутыми группами клиентов

3.2 СТРУКТУРА ТАБЛИЦЫ:

Таблица имеет фиксированную первую колонку (Клиент/Объект) 
и горизонтально прокручиваемые колонки дат.

Шапка таблицы (sticky top):

┌──────────────────────┬───────┬───────┬───────┬───────┬───────┬───────┬───────┐
│ КЛИЕНТ · ОБЪЕКТ      │ Пн 15 │ Вт 16 │ Ср 17 │ Чт 18 │ Пт 19 │ Сб 20 │ Вс 21 │
└──────────────────────┴───────┴───────┴───────┴───────┴───────┴───────┴───────┘

Стиль шапки:
- Фон #F8FAFC, sticky top: 0
- Текст: день недели на отдельной строке, дата под ним
- Шрифт: Nunito Sans 12px uppercase #64748B для дня недели, 
  SF Mono 13px weight 600 #0F172A для даты
- Сегодняшний день выделен: фон #EFF6FF, текст синий #4877A5
- Выходные дни: фон #FEF2F2 (очень мягкий), текст #94A3B8
- Padding 10px 8px, центрированное выравнивание
- Ширина колонки даты: 90-100px
- Нижняя граница 2px #E2E8F0

Первая колонка "Клиент · Объект":
- Sticky left: 0, ширина 280px
- Фон #FFFFFF, граница справа 1px #E2E8F0

3.3 ГРУППИРОВКА ПО КЛИЕНТАМ:

Каждый клиент — это группа строк. Структура группы:

Строка-заголовок клиента:
┌──────────────────────┬───────┬───────┬───────┬───────┬───┐
│ ▼ Лента (3 объекта)  │  20   │  20   │  28   │  23   │ … │
└──────────────────────┴───────┴───────┴───────┴───────┴───┘

- Иконка ChevronDown / ChevronRight (lucide) 14px — сворачивание
- Название клиента + количество объектов в скобках мелким текстом
- Цифры в ячейках = сумма всех объектов этого клиента в этот день
- Шрифт: Nunito Sans 14px weight 600 #0F172A
- Цифры: SF Mono 14px weight 600 #475569
- Фон строки: #F8FAFC (слегка темнее)
- Padding 12px

Строки объектов внутри группы:
┌──────────────────────┬───────┬───────┬───────┬───────┬───┐
│    БЦ Столица        │ 12/12 │ 12/8  │   —   │  15/4 │ … │
│    Парковка Лента    │  8/8  │  8/8  │  8/8  │  8/8  │ … │
│    ТЦ Лента-Восток   │   —   │   —   │ 20/15 │   —   │ … │
└──────────────────────┴───────┴───────┴───────┴───────┴───┘

- Объект с отступом слева 20px (визуальная иерархия)
- Шрифт названия: Nunito Sans 14px #0F172A
- Padding 10px

3.4 СОДЕРЖИМОЕ ЯЧЕЙКИ ОБЪЕКТА:

Каждая ячейка показывает данные по заявке этого объекта на эту дату.

ЕСЛИ ЗАЯВКА ЕСТЬ:
- Формат: "запл/нужно" в SF Mono 14px, например "12/8"
- Цвет фона ячейки зависит от зоны заявки:
  * Зелёная зона: фон #F0FDF4, граница #BBF7D0
  * Оранжевая (запл < нужно на 20%+): фон #FEFCE8, граница #FEF08A
  * Красная (запл < нужно на 50%+): фон #FEF2F2, граница #FECACA
  * Нейтральная (нет проблем): фон #FFFFFF
- Если "нужно" = "запл" — показываем "12/12" зелёным
- Если есть дефицит — число "запл" красным #EF4444
- Скругление 4px у фона ячейки
- Padding 6px 8px

ЕСЛИ ЗАЯВКИ НЕТ:
- В ячейке знак "—" серым #CBD5E1
- Фон #FFFFFF
- При наведении: фон #F8FAFC, курсор pointer, появляется 
  иконка Plus в центре #94A3B8 — намёк "можно создать"

ЕСЛИ НЕСКОЛЬКО ЗАЯВОК В ОДИН ДЕНЬ:
- Показываем сумму всех заявок в формате "20/15" 
  (сумма запл / сумма нужно)
- Маленькая иконка Layers (lucide) 12px справа от числа 
  означает "несколько заявок"
- Tooltip при наведении показывает разбивку:
  ┌──────────────────────────────────┐
  │ 15.05 · БЦ Столица — 2 заявки    │
  │                                    │
  │ #1236 (утро, 08:00–18:00): 8/12   │
  │ #1240 (вечер, 18:00–22:00): 7/3   │
  │                                    │
  │ Кликните для перехода к списку    │
  └──────────────────────────────────┘

3.5 СТРОКИ ИТОГОВ ВНИЗУ ТАБЛИЦЫ:

После всех клиентов — sticky bottom строки с итогами:

┌──────────────────────┬───────┬───────┬───────┬───────┬───┐
│ ИТОГО НУЖНО          │  35   │  41   │  43   │  33   │ … │
│ ЗАПЛАНИРОВАНО        │  35   │  38   │  40   │  20   │ … │
│ ДЕФИЦИТ              │   —   │  −3   │  −3   │ −13   │ … │
└──────────────────────┴───────┴───────┴───────┴───────┴───┘

Стиль:
- Фон #F8FAFC
- Шрифт первой колонки: Nunito Sans 12px uppercase weight 600 #64748B
- Цифры: SF Mono 14px weight 600 #0F172A
- "Дефицит" подсвечивается:
  * Если дефицит есть: красным #EF4444 weight 700
  * Если нет дефицита: серый "—"
- Верхняя граница 2px #E2E8F0
- Sticky bottom: 0

3.6 ВЗАИМОДЕЙСТВИЕ С ЯЧЕЙКАМИ:

При клике на ячейку С ЧИСЛОМ (есть заявка):
- Открывается мини-карточка поповер прямо над ячейкой:
  ┌────────────────────────────────┐
  │ #1236 · БЦ Столица              │
  │ 15.05 · 08:00 (10ч)             │
  │ Запл: 12/15  Резерв: −3         │
  │ Статус: Подбор завершён          │
  │                                 │
  │ [Открыть заявку →]              │
  └────────────────────────────────┘
- Кнопка "Открыть заявку →" переключает на вид "Список" 
  с выбранной заявкой в правой панели

При клике на ПУСТУЮ ячейку (заявки нет):
- Ячейка превращается в input-поле прямо в сетке (вариант C: 
  inline-редактирование)
- Курсор автоматически в поле, можно ввести число
- При Enter — создаётся черновик заявки в статусе "Создана" 
  с минимальными параметрами:
  * Клиент — из строки
  * Объект — из строки
  * Дата — из колонки
  * Количество людей — введённое число
  * Остальное (мастер, ставки, время) — пустые поля
- В правой части ячейки появляется маленькая иконка ✓ для 
  подтверждения и ✕ для отмены
- После создания ячейка показывает "0/N" (запл=0, нужно=N) 
  на красном фоне (так как никого ещё не записано)
- Toast сверху: "Заявка #1248 создана. Доукомплектуйте параметры."

При наведении на любую ячейку с заявкой:
- Курсор pointer
- Лёгкая тень shadow-sm у ячейки

3.7 ГОРИЗОНТАЛЬНЫЙ И ВЕРТИКАЛЬНЫЙ СКРОЛЛ:

- Первая колонка (Клиент · Объект) sticky left
- Шапка с датами sticky top
- Строки итогов sticky bottom
- Горизонтальный скролл активируется при периоде "Этот месяц" 
  и более (когда колонок дат больше чем влезает в экран)
- Вертикальный скролл — стандартный

ЧАСТЬ 5. ОБЩИЕ ТРЕБОВАНИЯ

ИКОНКИ — только lucide-react:
- LayoutGrid, List (переключатель видов)
- PanelRightClose, PanelRightOpen (кнопка панели)
- ChevronDown, ChevronRight (сворачивание групп)
- ChevronLeft, ChevronRight (перелистывание периода)
- Layers (несколько заявок в ячейке)

- CalendarX2 (пустое состояние)

ЗАПРЕТЫ:
- Никаких эмодзи
- Никаких звёзд рейтинга где-либо
- Не использовать ярко-красные/жёлтые цвета — только pastel

ЦВЕТА:
- Зоны: green #22C55E / #F0FDF4, yellow #EAB308 / #FEFCE8,

- Сегодняшняя дата: #EFF6FF / #4877A5

ШРИФТЫ:
- Заголовки и сегментные элементы — Nunito Sans
- Цифры в ячейках и итогах — SF Mono (для выравнивания колонок)

- Текущий вид "Список" с master-detail layout
