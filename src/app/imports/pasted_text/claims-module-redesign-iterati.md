- Виджеты "Баланс спроса" и "Требуют внимания" занимают слишком много места 
  — заявки должны быть первым что видит пользователь
- Кнопка "Создать заявку" слишком доминирует
- Канбан не работает и не нужен
- В заголовках карточек на первом месте должны быть клиент и объект, 
  а не номер заявки

ИЗМЕНЕНИЯ В ШАПКЕ ERP (верхняя панель всей системы):

В верхней панели справа рядом с иконкой уведомлений и аватаром пользователя 
добавить универсальную кнопку создания с выпадающим меню:

[🔔 3] [ + ] [Анна Петрова АП]
        │
        └─ При клике открывается dropdown:
           📋 Заявка
           🛒 Заказ клиента  
           🏢 Объект
           👤 Исполнитель
           👥 Клиент

Кнопка "+" — круглая или квадратная, 36×36px, с синей заливкой #4877A5 
или оранжевой #FF9900, белая иконка плюса внутри.
При наведении — тултип "Создать".
Dropdown открывается вниз, каждый пункт с иконкой и текстом.

ИЗМЕНЕНИЯ НА ГЛАВНОМ ЭКРАНЕ МОДУЛЯ "ЗАЯВКИ":

1. УДАЛИТЬ ИЗ ШАПКИ МОДУЛЯ:
   - Кнопку "+ Создать заявку" (переехала в глобальную шапку)
   - Переключатель видов "Список / Канбан / Табель" (теперь только список)

2. УДАЛИТЬ ПОЛНОСТЬЮ:
   - Большую карточку "Баланс спроса" (перенесём в модуль Дашборд позже)
   - Большую карточку "SLA 17:00"
   - Секцию "Требуют внимания (2)" с большими красными/оранжевыми карточками

3. ДОБАВИТЬ ТОНКУЮ ИНФОРМАЦИОННУЮ ПОЛОСКУ СВЕРХУ
   (вместо удалённых виджетов):
   
   Одна горизонтальная строка, высота ~40px, светлый фон #F8FAFC:
   
   🟢 Сегодня 92% · 🟡 Завтра 52% · 🔴 Послезавтра 28%  |  SLA 17:00: 312/340 · до дедлайна 2ч 14мин  |  ⚠️ 2 требуют внимания →
   
   Элементы разделены вертикальными тонкими линиями.
   "2 требуют внимания" — кликабельная ссылка синего цвета.
   Вся полоска должна быть компактной, не привлекать основное внимание.

4. ЗАГОЛОВОК МОДУЛЯ — УПРОСТИТЬ:
   Просто заголовок "Заявки" слева, без кнопок справа.

5. ТАБЫ ПО СТАТУСАМ ПАЙПЛАЙНА (как и было, но теперь это главный элемент):
   [Все 45] [Новые 5] [Планирование 12] [Выход 8] [Закрытие смен 3] [Согласование смен 4] [Выплата 2] [Завершено]
   По умолчанию "Все".

6. ТАБЫ ПО ДАТАМ (под статусными табами):
   [📅 Сегодня 12] [📅 Завтра 23] [📅 Далее 45]

7. СПИСОК ЗАЯВОК — НОВЫЙ ФОРМАТ КАРТОЧКИ:

   Каждая карточка имеет два уровня информации:
   
   ПЕРВАЯ СТРОКА (крупно, главное):
     "Лента • БЦ Столица"
     Размер шрифта ~18px, жирный, цвет #0F172A
   
   ВТОРАЯ СТРОКА (мелко, служебное):
     "📅 15.05 09:00 · 👥 12 чел · #1236"
     Размер шрифта ~13px, цвет #64748B (gray-500)
   
   ТРЕТЬЯ СТРОКА (бейджи со статусами):
     [🟢 Зелёная (88/100)] [📊 Закрытие: 12/12 (100%)] [👥 НПД: 75%] 
     [🎯 Прогноз явки: 92%] [✅ Координатор назначен]
   
   Цветная полоска слева 4px шириной (зелёная/жёлтая/красная в зависимости от зоны).
   При наведении — светлая подсветка фона.
   Клик открывает детальную страницу заявки.

ОБЩИЕ ТРЕБОВАНИЯ К ВЁРСТКЕ:
- Цвета: #FF9900 (orange), #4877A5 (blue), #22C55E / #EAB308 / #EF4444 (зоны)
- Фоны: #FFFFFF (основной), #F8FAFC (secondary)
- Шрифты: Montserrat (заголовки), Nunito Sans (текст)
- Скругления: 8px (карточки), 6px (кнопки), 20px (бейджи-pills)
- Отступы между карточками списка — 8-12px
- Активный таб — синий текст #4877A5, подчёркнутый снизу 2px
- Неактивные табы — серый #64748B

КРИТИЧНО: основное пространство экрана должно занимать СПИСОК ЗАЯВОК, 
а не виджеты сверху. Виджеты — компактная полоска, списки заявок — главное.
